# 🌱 Cozy Quest

### Your KTU S3 studies, reimagined as a cozy RPG adventure.

Cozy Quest is a cozy, pixel-art-inspired study companion designed around the KTU S3 syllabus.

It combines academic progress tracking with RPG-style progression, daily quests, achievements, collectible companions, an evolving adventure world, and a personal study library.

Complete topics, earn XP, unlock new realms, collect rewards, and watch your adventurer evolve as you make progress.

**Study a little. Complete a quest. Earn XP. Keep moving forward.**

# ⚔️ 5. Adventure Guild

The Adventure Guild rewards additional academic activities beyond your regular syllabus checklist.

There is one important rule:

**You must complete at least one syllabus topic during your current study session to unlock Guild activities.**

Each completed topic gives you one Guild Pass.

You can use these passes to log additional activities:

| Guild Activity | XP Reward |
|---|---:|
| Solve 3 questions | +15 XP |
| Complete 1 PYQ | +20 XP |
| Complete a full lab program | +25 XP |
| Complete module revision | +50 XP |

Each logged activity consumes one available Guild Pass.

This system encourages you to combine syllabus completion with actual question practice, programming, and revision.

💎 The journey continues into breathtaking highlands.

# 💾 11. Saving Your Progress and Automatic Backup

Cozy Quest is designed to run locally on your computer.

Your progress is automatically saved in your browser using Local Storage and IndexedDB.

There is also a folder-based backup system that lets you keep an external copy of your progress.

### First-Time Backup Setup

You only need to connect your backup folder once.

1. Open Cozy Quest.
2. Navigate to **Settings**.
3. Find the **Automatic Computer Backup** section.
4. Click **Choose Backup Folder**.
5. Your browser will open a folder-selection window.
6. Select the folder where you want Cozy Quest to store your backup files.
7. Grant the requested folder permission.

Once connected, Cozy Quest creates the following backup structure inside your selected folder:

```text
Your Selected Folder/
│
├── cozy-quest-backup.json
│
└── snapshots/
    ├── backup-2026-11-14T....json
    ├── backup-2026-11-14T....json
    └── ...
```

The main JSON file contains your saved adventure state and Library resource information.

The snapshots folder stores dated backup copies.

### What Happens Next?

After the first setup, Cozy Quest stores the selected folder connection in browser storage.

When you open Cozy Quest again, it attempts to restore the saved folder connection.

When permission is available, future progress changes automatically update the external backup.

If the browser requires permission again, simply open Settings and click **Reconnect**.

You can also use **Back Up Now** whenever you want to create an immediate backup.

### What About Google Drive?

You can select a folder inside your locally available Google Drive for Desktop directory.

Google Drive can then synchronise those backup files through its own desktop application.

This gives you another way to keep a copy of your progress.

### Important: Backing Up Your PDFs

The automatic folder backup contains your adventure progress and Library resource metadata. It does not include the actual imported PDF files.

If you want to back up your complete Library, including its imported PDFs, use the Complete ZIP Backup option.

# 📦 12. Recovery and Archives

Cozy Quest includes additional export and restore options.

You can find them under **Settings → Recovery & Archives**.

### Export Progress JSON

Downloads a JSON file containing your adventure progress.

Useful for keeping a separate copy of your saved progress.

### Export Complete ZIP (Data + PDFs)

Creates a complete ZIP archive containing:

- Your adventure progress.
- Library resource metadata.
- Imported PDF documents.

This is the recommended option when you want to preserve your complete study library.

### Restore Progress

You can restore your saved data using either:

- A previously exported JSON progress file.
- A complete ZIP backup.

Select the corresponding restore option and choose your backup file.

### Reset All Adventure Progress

There is also an option to reset your adventure progress.

Use this carefully, as resetting clears your current adventure progress.

# 🚀 Getting Started

Cozy Quest is designed to run locally. You do not need a hosted website, an account, or a backend server.

### Method 1 — Download ZIP

1. Visit the [Cozy Quest GitHub Repository](https://github.com/adhyu8/Cozy-Quest).
2. Click **Code → Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open the extracted project folder.
5. Open `index.html` in your browser.

### Method 2 — Clone the Repository

If you have Git installed, open your terminal and run:

```bash
git clone https://github.com/adhyu8/Cozy-Quest.git
```

Open the downloaded project folder and launch `index.html`.

### Browser Compatibility

For folder-based automatic backups, use a supported Chromium-based browser such as Google Chrome or Microsoft Edge.

The folder-selection feature requires a supported secure context. If it does not work when opening the file directly, run the project using a local development server such as VS Code Live Server.

The application itself does not require a hosted deployment.

# 🎯 The Idea Behind Cozy Quest

Cozy Quest started with a simple idea:

**What if studying felt a little more like progressing through an adventure?**

Traditional study trackers can sometimes feel repetitive. Cozy Quest experiments with a different approach by combining academic organisation with game-inspired progression.

Every topic completed is a quest finished.

Every XP earned is progress made.

Every realm unlocked is another milestone reached.

The goal isn't to turn studying into a competition. It's to make everyday progress more visible, rewarding, and enjoyable.
